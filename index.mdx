NanoJev is a nano replica of [Jev](https://typesafe.ai/blog/introducing-system-one-models-and-jev) — a 0.6B decision model built on Qwen3-0.6B. Feed it a state and a set of questions and it returns a complete probability distribution over every candidate in a single forward pass. No output-token decoding, no generation loop. Batch multiple independent states and questions together and they all resolve in one backbone forward.

## How it works in 60 seconds

<Steps>
  <Step title="Define your state and questions">
    A **state** is the shared context — text, JSON object, or array. Each **question** asks the model to judge that state using a Choice, Boolean, or Score primitive.
  </Step>
  <Step title="Send a batched request">
    Package one or more states and their questions into a JSON payload and POST it to `/api/evaluate`. Multiple states are evaluated in a single backbone forward.
  </Step>
  <Step title="Read the probability distributions">
    Each answer contains the full distribution over its candidates. Use the probabilities for greedy selection, ranked scoring, or probability sampling — no sampling loop needed.
  </Step>
  <Step title="Train or fine-tune your own checkpoint">
    Provide a JSONL dataset with `gold_probs` targets, run `train_pipeline_decisions.py`, and extend the checkpoint with your own task data.
  </Step>
</Steps>

## Key capabilities

<CardGroup cols={3}>
  <Card title="Zero decoding overhead" icon="bolt">
    Decisions come directly from a forward pass. No autoregressive token generation, no sampling loop.
  </Card>
  <Card title="Dynamic candidate sets" icon="sliders">
    Choice questions accept 2–255 named candidates per question. Candidate sets can differ between questions in the same batch.
  </Card>
  <Card title="Complete distributions" icon="chart-pie">
    Every response includes probabilities for all candidates — use the same output for greedy selection, ranking, or sampling.
  </Card>
  <Card title="Parallel decisions" icon="layer-group">
    Batch independent states and questions together. One backbone forward handles 6 states, 18 questions, and 44 candidate paths simultaneously.
  </Card>
  <Card title="End-to-end pipeline" icon="diagram-project">
    Programmatic data generation, training, evaluation, and serving are all included in the repository.
  </Card>
  <Card title="Calibrated probabilities" icon="bullseye">
    RLCD-inspired training with CE, Brier, and paired proper-reward objectives for calibrated event prediction.
  </Card>
</CardGroup>
